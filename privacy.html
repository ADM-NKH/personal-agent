Privacy policy

Last updated October 17, 2026

Personal Agent is a private tool with a single user, its owner (Adam Nikhamovsky). This page explains what it does with Google user data.

What it accesses

  • Free/busy times of the owner's Google Calendar, to find when he is available.
  • Calendar events that Personal Agent itself creates (meetings he agreed to, invitations, workouts): it creates, moves and deletes only those events.

How the data is used and stored

  • Data is used only to keep the owner's own calendar and reminders up to date.
  • It is processed and stored on the owner's own computer. Sign-in tokens are kept in the macOS Keychain.
  • Google user data is not sold, shared with third parties, or used for advertising.

Personal Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
